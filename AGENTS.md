# Vacancy Collector

- Сохраняй структуру навыка и контракт из [технической спецификации](TECHNICAL_SPECIFICATION.md).
- Используй Windows и Python 3.13.5 со стандартной библиотекой. Обрабатывай локальные файлы.
- Читай исходные входы без изменения. Согласуй обновление существующего реестра перед запуском.
- Для проверок используй отдельную рабочую копию и вымышленные данные.
- Храни рабочие входы, реестры, журналы и отчёты за пределами отслеживаемых файлов.
